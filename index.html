下載 YT 下載器 App

下載需要在你的電腦上進行（網頁本身無法執行 yt-dlp）。安裝桌面 App 就能直接使用，已內建 yt-dlp、FFmpeg，不用另外安裝任何東西；裝好後也可以繼續用這個網頁操作。

1. 下載並安裝
Windows 10 / 11 macOS（Apple 晶片）

App 沒有付費的數位簽章，第一次下載、開啟時系統會跳出警告，這不代表有病毒，照下面步驟放行即可。
Windows 10／11：瀏覽器說「通常不會下載此檔案」時按「保留」。執行安裝精靈，出現「Windows 已保護您的電腦」時按「其他資訊」→「仍要執行」，之後從「開始」功能表開啟「YT 下載器」。防毒軟體隔離了檔案時，請到隔離區還原並加入例外。 詳細步驟
macOS（Apple 晶片，macOS 14 以上）：打開 .dmg，把「YT 下載器」拖進「應用程式」。① 先雙擊開啟一次（會被擋下）② 到「系統設定 → 隱私權與安全性」，在最下方按「仍要打開」③ 只有顯示「已損毀」時，才在「終端機」執行一次 xattr -dr com.apple.quarantine "/Applications/YT 下載器.app"。 詳細步驟
Intel Mac 不支援（點左上角 →「關於這台 Mac」，「晶片」寫 Apple M 開頭才能使用）。
檔案預設存在「下載」資料夾裡的 YT-Downloads。 所有版本與說明

進階：用 Python 原始碼執行（Linux 等，開發者用） 
git clone https://github.com/Archer8685/yt-dl.git
cd yt-dl
start.bat        # Windows
./start.sh       # macOS / Linux

需要 Python 3.10+、FFmpeg、Node.js 或 Deno。

2. 已安裝 App？開啟後這個網頁會自動連上（或手動輸入位址）

Chrome 若跳出「允許存取區域網路裝置」請選允許。Safari 不支援從 https 網站連線到本機，請改用 Chrome / Edge / Firefox，或直接開 http://127.0.0.1:8765。

登入 YouTube 帳號

登入後可下載 Premium 1080p 高位元率、頻道會員影片與年齡限制影片。不會要你輸入密碼，而是讓下載引擎借用你瀏覽器的登入狀態（Cookie）；Cookie 只存在你自己的電腦。

  1. 在瀏覽器登入 YouTube

    用你平常的瀏覽器打開 YouTube，確認右上角有你的頭像（Premium 帳號左上角會顯示 Premium 標誌）。

    開啟 YouTube ↗
  2. 選擇你登入的瀏覽器
  3. 測試並套用
    ⚠ Windows 版 Chrome / Edge 等瀏覽器會鎖住並加密 Cookie。請先完全關閉該瀏覽器（包含背景執行）再按測試；若仍失敗，請改用 Firefox 或「方法二」。
  1. 安裝匯出擴充功能

    安裝「Get cookies.txt LOCALLY」（只在本機匯出，不會上傳到任何伺服器）。

    Chrome / Edge / Brave ↗ Firefox ↗
  2. 在 YouTube 頁面匯出

    打開 youtube.com（已登入）→ 點工具列的擴充功能圖示 → 按 Export，會下載一個 www.youtube.com_cookies.txt。

    💡 小技巧：YouTube 會定期更換 Cookie，讓匯出的檔案失效。最穩的做法是開無痕 / 私密視窗登入 YouTube 後匯出，然後直接關閉那個視窗（擴充功能需允許在無痕模式執行）。
  3. 把檔案拖進來
    📄 拖曳 cookies.txt 到這裡，或點此選擇檔案
    或直接貼上檔案內容
